# ポケカ 優勝デッキまとめ

ポケモンカードの大会結果から **優勝・準優勝のデッキだけ** を毎日自動で集めて、
8歳の子どもが一人で読めるページにする。

店舗ごとにページを行き来しなくても、1つのページで「いま何が勝っているか」が
分かるようにするのが目的。

## 子ども向けページ

Settings > Pages を有効にすると、ここに公開される。

**https://macsa2ki25-eng.github.io/pokeca-decks/**

- 文字入力なし。操作は大きなボタンのタップだけ
- 文言はひらがな、日付は「8がつ9にち」形式
- カードをタップすると公式の**本物の60枚レシピ**が開く
- シティリーグ / ジムバトル を切り替えられる
- 「つよい じゅん」で優勝回数ランキング

スマホの共有メニューから「ホーム画面に追加」すると、アプリのように使える。

## 使い方

```bash
pip install -r requirements.txt

python -m src.pokeca.cli collect     # 収集して results.json を更新
python -m src.pokeca.cli build       # site/index.html を生成
python -m src.pokeca.cli rank        # 直近1週間の優勝ランキング
python -m src.pokeca.cli list --rank 1 --event city   # シティリーグの優勝だけ
```

毎朝8時 (JST) に GitHub Actions が自動で収集・公開する。
`Actions > Collect winning decks > Run workflow` で手動実行もできる。

## 仕組みと注意点

詳細は **[docs/POKECA_GUIDE.md](./docs/POKECA_GUIDE.md)** に書いてある。
収集元のHTML構造、パーサーの直し方、詰まったときの調べ方まで含む。

要点だけ:

- 収集元は [ポケカブック](https://pokecabook.com/) の2種類の記事
  - シティリーグのまとめ記事 → 日付・店舗・順位・デッキコード
  - デッキ別ページ → デッキ名・ジムバトルの優勝
- デッキコードを共通の識別子にして両者を突き合わせる
- **転載しない**。保存するのは事実データとリンクだけで、記事本文もレシピ画像も
  コピーしない。デッキの中身は公式または元サイトを開いて見る導線にしている
- **プレイヤー名は保存しない**
- robots.txt を確認し、アクセス間隔を1.5秒あける。デッキ別ページは1枚500KB前後
  あるので、日ごとに25デッキずつ巡回して3日で一周する

## このリポジトリを分けている理由

もともと別のリポジトリに同居させていたが、そこの GitHub Pages は
生徒が使っている英単語学習サイトを配信していた。
ポケカのワークフローがそれを上書きしてしまったため、専用リポジトリに分離した。

**このリポジトリの Pages はポケカのページ専用にすること。**
